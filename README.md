# PassiveMobs

Мод для **Minecraft 1.7.10** і **Forge 10.13.4.1614**, з яким звичайні ворожі моби не атакують гравця. Вони залишаються у світі та продовжують рухатися — перемикати гру на мирну складність не потрібно.

Боси за замовчуванням залишаються ворожими, зокрема боси підземель Galacticraft. PvP і можливість гравця атакувати мобів не змінюються.

## Завантаження та встановлення

1. Встановіть Minecraft 1.7.10 з Forge 10.13.4.1614.
2. Завантажте **`passivemobs-1.4.0.jar`** зі [сторінки останнього релізу](https://github.com/kvxshenyjbetxn/passivemobs/releases/latest) (розділ **Assets**, не архів вихідного коду).
3. Закрийте гру або зупиніть сервер і покладіть JAR у папку `mods` потрібної збірки.
4. Видаліть стару версію PassiveMobs, якщо вона є, і запустіть гру або сервер знову.

Мод працює в одиночній грі та на Forge-сервері. Для мережевої гри встановіть його на сервер; лише клієнтська копія не змінить поведінку мобів на чужому сервері.

## Команди

Потрібні права оператора (рівень 2) або дозволені чіти в одиночній грі.

| Команда | Дія |
| --- | --- |
| `/passivemobs` | Показати, чи ввімкнений мод |
| `/passivemobs on` | Увімкнути мирну поведінку мобів |
| `/passivemobs off` | Повернути звичайну поведінку |
| `/passivemobs reload` | Перечитати налаштування з файла |

`on` і `off` діють до перезапуску або `reload`. Для постійної зміни відредагуйте конфіг.

## Налаштування

Після першого запуску з’явиться файл `config/passivemobs.cfg`:

- **`enabled=true`** — мод увімкнений; `false` вимикає його.
- **`allowBosses=true`** — боси залишаються ворожими. Рекомендовано залишити так, щоб не заважати боям і механікам підземель.
- **`excludedEntities`** — винятки для окремих мобів або босів з інших модів. Зазвичай змінювати не потрібно; для винятку вкажіть повну Java-назву класу або інтерфейсу, по одній на рядок.

Після редагування виконайте `/passivemobs reload` або перезапустіть гру/сервер.

## Якщо щось не працює

- **Моб усе ще атакує:** перевірте `/passivemobs`, налаштування та встановлення мода на сервері. Боси й моби зі списку винятків залишаються ворожими навмисно. Деякі модові моби з власною системою атак можуть бути несумісні.
- **Не з’явився бос Galacticraft:** залиште `allowBosses=true`, повністю вийдіть із кімнати й зайдіть знову. Мод не відновлює вже пошкоджені підземелля.
- **Після оновлення нічого не змінилося:** потрібен повний перезапуск, а не лише `reload`. У папці `mods` має залишитися одна версія PassiveMobs.

Сумісність з усіма мобами та босами модпаків, зокрема GTNH, не гарантується. Про проблеми повідомляйте в [Issues](https://github.com/kvxshenyjbetxn/passivemobs/issues), додавши версію мода, назву збірки та лог гри/сервера.

## Для розробників

Потрібна Java 8. Збірка: `./gradlew clean build` (Windows: `gradlew.bat clean build`). Готовий JAR: `build/libs/passivemobs-1.4.0.jar`.

Збірка включає регресійні перевірки трансформації класів Minecraft; вони не замінюють перевірку в грі.

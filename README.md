# PassiveMobs

Мод для Minecraft 1.7.10 / Forge 10.13.4.1614: звичайні моби не обирають гравця бойовою ціллю. Боси за замовчуванням залишаються ворожими, щоб не ламати бої та активацію зустрічей.

## Як працює

- Точковий ASM-фільтр полів `EntityLiving.attackTarget`, `EntityCreature.entityToAttack` і `EntityGhast.targetedEntity` покриває сучасний AI (зокрема блейзів), старий AI та окрему систему гастів.
- `EntityAITarget.isSuitableTarget` відхиляє гравців лише для мобів, на яких діє мод.
- Forge-івенти очищають залишкові цілі й помсту та скасовують шкоду від таких мобів, включно зі снарядами з указаним власником.
- Павуки не заморожуються; рух, гравітація, шкода мобам, PvP і глобальний пошук гравців не блокуються.
- Немає втручання у спавн, скасування оновлень сутностей чи фільтрації довільних методів за сигнатурою.

## Конфіг

Forge створює файл `config/passivemobs.cfg`. `/passivemobs reload` перечитує саме файл, переданий Forge, разом з усіма винятками.

```ini
general {
    B:enabled=true
    B:allowBosses=true
    S:excludedEntities <
    >
}
```

`allowBosses=true` повністю виключає сутності, які реалізують `IBossDisplayData` або `micdoodle8.mods.galacticraft.core.entities.IBoss`: вони можуть обирати ціль і завдавати шкоди. Інтерфейс Galacticraft перевіряється за назвою, включно з успадкованими інтерфейсами, без обов’язкової залежності від Galacticraft. `false` застосовує до них звичайне придушення агресії, але може заважати механікам зустрічей.

Для модових босів або допоміжних сутностей активації, які не реалізують цей інтерфейс, додайте **повну Java-назву класу або інтерфейсу** в `excludedEntities`, по одній на рядок. Виняток діє і на підкласи та реалізації інтерфейсу; їхні цілі та шкода залишаються незмінними. Назви класів залежать від конкретного мода.

Довільний модовий AI з власними полями цілей або атаками без зазначеного власника може потребувати окремої інтеграції. Сумісність з усіма босами GTNH не гарантується без перевірки конкретної збірки.

## Команди (OP level 2)

```
/passivemobs
/passivemobs on
/passivemobs off
/passivemobs reload
```

`on`/`off` перемикають мод до перезапуску або перечитування конфіга, не записуючи файл.

## Збірка й перевірки

Java 8, Gradle Wrapper:

```bash
./gradlew clean build
# → build/libs/passivemobs-1.4.0.jar
```

`build` включає `transformerRegression`: перевірку байткоду для MCP/SRG/Notch, відсутності змін сторонніх setter-методів і трансформації реальних класів Minecraft у dev/production-іменуванні. Ці перевірки не замінюють ігрового тестування босів із модів.

Після заміни старого JAR потрібен повний перезапуск гри/сервера, оскільки ASM застосовується під час завантаження класів. Не залишайте одночасно дві версії мода.

## Galacticraft

Боси підземель Galacticraft за замовчуванням виключені через `allowBosses=true`; вимикати весь PassiveMobs для бою з ними не потрібно. Це також охоплює босів доповнень, які реалізують Galacticraft `IBoss` або стандартний `IBossDisplayData`.

У перевіреному коді GTNH Galacticraft спавнер створює боса при переході гравця ззовні всередину кімнати, а не за фактом агресії. Якщо кімната залишилася порожньою, спробуйте повністю вийти з неї й зайти знову. Мод не скидає збережені стани `spawned`/`defeated` і не відновлює автоматично пошкоджені підземелля. Причину попередніх збоїв появи без конкретної версії Galacticraft та логів не підтверджено.

Перевірені джерела: [спавнер](https://github.com/GTNewHorizons/Galacticraft/blob/master/src/main/java/micdoodle8/mods/galacticraft/core/tile/TileEntityDungeonSpawner.java), [місячний бос](https://github.com/GTNewHorizons/Galacticraft/blob/master/src/main/java/micdoodle8/mods/galacticraft/core/entities/EntitySkeletonBoss.java).

## Ручна перевірка у грі

1. У Survival перевірити блейза, гаста, зомбі й павука: без переслідування та атак, зі збереженням природного руху.
2. Перемкнути `off` → `on` поруч із уже агресивними мобами, зокрема гастом.
3. Перевірити появу й активацію потрібних босів з `allowBosses=true`; за необхідності додати клас тригера або боса до винятків.
4. Перевірити PvP та шкоду гравця по мобах/босах.
